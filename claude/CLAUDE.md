# System-level Claude Code instructions

- Do not add comments, docstrings, or type annotations unless they add value to the code
- Use, short but precise, caveman-like commit messages and comments, do not overexplain
- When writing comments for generic changes, do not explain them by the specific feature we are working on!
- Do not add co-authored tags to commit messages
- Do not commit superpowers design documents/plans
- Do not use the "chooser" interface for complex choices with long explanation, as it only displays a short info, hiding details
- When writing text (commit messages, comments, etc) use only ASCII characters and try to avoid typical AI tells!
- When working on generic text, try to mimic my writing style -- we'll keep notes about it in WRITING_STYLE.md in this directory, you can update it as needed
